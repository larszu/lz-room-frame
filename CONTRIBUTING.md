# Contributing to LZ Room Frame

Bug reports and ideas are welcome as [issues](https://github.com/larszu/lz-room-frame/issues). The source is public but not open source (see [LICENSE](LICENSE)); pull requests are read, but changes are made in this repository.

Please include in a bug report: operating system, LZ Room Frame version, the input (camera or capture card, resolution) and what was framed wrongly – a screenshot of the *Live* view helps.

## Development

Node.js 24 and npm. `npm install`, then `npm run dev` (Vite on port 4196 plus Electron) and `npm test` before every push.
